## 日本語要約
v0.25.0(W29 の INT4/NVFP4 KV cache 追加リリース)直後のパッチ。量子化まわりでは **#48330: FlashInfer の fused allreduce + RMSNorm + static-quantization パターンが dtype 混在グラフ(例: BF16 残差ストリーム + FP32 RMSNorm 重みの NVFP4 モデル、Gemma/Qwen 系)を誤マッチして hidden state を破壊し `!!!!!` 連発などのゴミ出力を生む問題**に dtype 一致ガードを追加。同一 dtype のモデルは fusion をフル維持。もう1件は TorchCodec/FFmpeg 由来の起動ブロック修正。

## 注目度コメント
NVFP4 モデル(まさに Gemma/Qwen 系)を vLLM でマルチ GPU 評価する際に直撃する correctness バグの修正で、手元評価の前提に関わる。NVFP4 focus + vllm-ready bump で high。**W30 時点の評価は v0.25.1 以降を使うこと**。
