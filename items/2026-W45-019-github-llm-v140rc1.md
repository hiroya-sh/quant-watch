## 日本語要約

TRT-LLM v1.4.0 の最初の RC。**DeepSeek-V4.1-Flash #19727 サポート**、**NVFP4 GLM-5.3-Flash チェックポイント #20127**、**Qwen3.8-Flash-Next NVFP4(experimental Modeling V2) #20143**、**Hopper 上の Nemotron-H NVFP4 の W4A16 自動フォールバック削除 #15772**。KV cache: **KV cache manager V2 と Python KV cache transceiver がデフォルトに(BREAKING) #17495**、**NVFP4 cold-page compression のための RoPE 精度オプション #19391**、**Mooncake connector を KV V2 と統合 #19171**。Rubin 向け **Kimi K3 最適化 #19960**、**MiniMax-M3 の NVFP4 KV ホストオーバーヘッド削減 #19974**、**NVFP4 FC1 weight layout(Rubin CuTe DSL MoE) #20181**。

## 量子化関連の変更点

- 新規モデル: DeepSeek-V4.1-Flash #19727、NVFP4 GLM-5.3-Flash #20127、Qwen3.8-Flash-Next NVFP4 experimental #20143、Nemotron-H NVFP4 の W4A16 fallback 削除 #15772
- **KV cache V2 デフォルト化 (BREAKING)** #17495 — PR#13 (W43) の v0.32.0 と同期した大規模再編
- RoPE 精度オプション for NVFP4 cold-page compression #19391
- Mooncake connector + KV V2 統合 #19171
- MiniMax-M3 NVFP4 KV ホストオーバーヘッド削減 #19974
- NVFP4 FC1 weight layout(Rubin CuTe DSL MoE) #20181
- PrimTS dense BF16 / mixed BF16-FP8 / FP8 context attention #20006

## 影響範囲

- **BREAKING**: KV cache manager V2 が既定に。既存の V1 前提コード(trt-llm 直接 API)は改修が必要。
- Hopper での Nemotron-H NVFP4 の W4A16 自動フォールバックが外れたため、**Hopper 上では NVFP4 直実行が必要**(fallback 期待のコードは失敗する可能性)。
- モデル追加分(DeepSeek-V4.1-Flash / NVFP4 GLM-5.3-Flash / NVFP4 Qwen3.8-Flash-Next)は Modeling V2 + V2 KV の組合せを前提。
