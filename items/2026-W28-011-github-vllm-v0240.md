## 日本語要約
vLLM v0.24.0 メジャーリリース。W27 v0.23.1 hotfix から 10 日での大型更新。Llama-4 公式量子化レシピ（W28-009）の完全対応、PolarQuant-KV（W27-001）の実験的統合、NVFP4 KV native カーネルの Blackwell / Hopper 対応、compressed-tensors 0.19.0 (W28-014) への依存更新が主要変更。MoE ルーティングの MXFP4-MoE 経路も TP=8 相当までスケール検証済み。

## 量子化関連の主要変更
- **Llama-4 5 構成統合対応**: `--quantization llama4-nvfp4 | llama4-mxfp4-moe | llama4-awq-int4 | llama4-gptq-int4 | llama4-fp8` の 5 CLI プリセットを追加（PR #16021）
- **PolarQuant-KV 実験統合**: `--kv-quant polar-3bit` オプション追加（experimental フラグ、W27-001 のリファレンス実装）
- **NVFP4 KV Blackwell native**: WGMMA + TMA 経路の fused kernel を LazyDelegate 化、H200 も同カーネルパスで動作可能に
- **compressed-tensors 0.19.0**: Llama-4 レシピと Qwen3.6 レシピの互換テーブル追加
- **MXFP4-MoE 大規模検証**: Kimi-K2.6-140B / DeepSeek-V4-Pro を TP=8, PP=2 で MXFP4-MoE 実行可能に

## その他変更
- Llama-3.2 GPTQ INT4 の ROCm 経路の安定化
- Gemma-4-31B の InternVL 系マルチモーダル互換性向上
- v0.24.0-p1 hotfix 予定（次週）
