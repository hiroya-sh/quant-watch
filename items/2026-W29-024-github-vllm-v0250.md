## 日本語要約
vLLM v0.25.0(558 commits)。量子化まわりの大物: **Triton INT4 per-token-head KV cache 量子化 (#40835)** と **NVFP4 KV cache + skip-layers sliding window (#42890)** が入り、FP8 以外のネイティブ KV 量子化パスがついに vLLM 本体に登場。加えて 2/3/5/6/7-bit の pack-quantized weight-only 推論「Humming」(#46389)、MiniMax-M3 ModelOpt NVFP4 (#46756)、NVFP4 MoE MLP kernel 融合 (#44667)、Marlin の MoE 拡張、新モデル Hy3 (#47192) / GLM-5 / DeepSeek-V3.2 対応。

## 監視方針への影響(重要)
- priorities.yml の vllm_runnable_ground_truth は「FP8 KV が唯一のネイティブ KV 量子化」と注記していたが、**本リリースで INT4 KV(per-token-head)と NVFP4 KV が公式に追加**。ground truth の更新が必要
- Humming(2-7bit pack-quantized)は新規手法タグ候補
