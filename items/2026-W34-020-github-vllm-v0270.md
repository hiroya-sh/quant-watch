## 日本語要約
561 commits の大型リリース。**FlashAttention 4 (SM100) が FP8 KV cache と headdim-256 をサポート**し、Kimi K3(compressed-tensors 量子化 checkpoint 含むフルスタック)対応、Qwen3.5 dense/MoE 追加。量子化面では **FP4 Qutlass 統合(compressed-tensors)、ReLU2 NVFP4 の CuTeDSL MoE、INC の MXFP8 linear、DeepSeek-V4/Kimi-K3 の compressed-tensors checkpoint** など多数。DeepSeek-V4 は MXFP4 indexer KV cache などで性能改善。

## 量子化関連の変更点
- 新規対応手法/フォーマット: FP4 Qutlass (compressed-tensors, #43229), NVFP4 CuTeDSL MoE (#49580), MXFP8 linear in INC (#47514), FlashAttention4 FP8 KV cache (#42569)
- 既存手法の改善: Quark w8a8-int8 (#46765) / MXFP4, MoeWNA16 の MK oracle 移行
- 対応モデル拡張: DeepSeek-V4 / Kimi-K3 の compressed-tensors checkpoint, Gemma-4 ViT CUDA graph

## 影響範囲
- ユーザ視点の変化: Blackwell SM100 で FP8 KV cache が FA4 経路で使える。DeepSeek-V4/Kimi-K3 の量子化 checkpoint を直接 serving 可能
- API/CLI 変更の有無: PyTorch 2.13 への破壊的環境更新、FusedMoE→FusedMoEFactory 改名

## 注目度コメント
focus の NVFP4・moe-quant に合致し vllm-ready 付与。FP8 KV cache が FA4 native で乗った点は KV 量子化評価の実行環境として最重要。
