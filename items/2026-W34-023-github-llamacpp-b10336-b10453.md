## 日本語要約
週内55ビルド(b10336〜b10453)の量子化関連を集約。**Metal に TQ2_0(三値・2bit/要素)型を追加**(b10414)、compressed-tensors の "mxfp4-pack-quantized" routed expert を **bf16 往復(~5.5TB)なしに losslessly GGUF 化**する遅延 repack(b10448、Kimi-K3-Q2_K を 8×B200 で検証)、OpenVINO backend の gpt-oss MoE / mxfp4 有効化と compile 時 requant のストリーミング化(b10419)、SYCL の Q3_K/Q4_K/Q6_K ESIMD kernel と q4_K FFN GLU 融合(b10408/b10427)、Vulkan の mxfp4 kvalues 修正。

## 量子化関連の変更点
- 新規対応手法/フォーマット: TQ2_0 ternary (Metal), compressed-tensors mxfp4-pack → GGUF 直変換
- 既存手法の改善: SYCL Q3/Q4/Q6_K ESIMD kernel, q4_K dense FFN の gate+up+GLU 融合(+2〜2.8%)
- 対応モデル拡張: Kimi-K3 GGUF (MXFP4 lossless repack), gpt-oss on OpenVINO

## 影響範囲
- ユーザ視点の変化: MXFP4 native 配布モデル(Kimi-K3 等)を巨大な bf16 往復なしに GGUF 化できる。三値 TQ2_0 が Metal で動く
- API/CLI 変更の有無: 大きな破壊的変更なし(週次ビルド)

## 注目度コメント
MXFP4 native 配布 → GGUF 直変換の流れは W33 の潮流の継続。llamacpp-ready。
