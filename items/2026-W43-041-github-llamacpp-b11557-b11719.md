llama.cpp の window 内 per-build 95 本(b11557〜b11719)。v0.7.0 に含まれない主な量子化関連変更: Hexagon q1_0 + Hadamard MUL_MAT / GET_ROWS(flat+tiled) 対応(b11717)、OpenCL **MXFP4 MoE bin kernel for Adreno X1**(b11702)、SYCL **wide stores for Q4_K/Q5_K weight dequant**(b11685)、kleidiai **SME2 Q4_K/Q6_K matmul**(b11604)、SYCL **IQ3_S/IQ3_XXS persistent reorder**(Qwen3.8-27B-GSQ-RCO-IQ3_S/MTP で検証、b11636)、Hexagon tensor repack / tiled K-quant GET_ROWS(b11680)、FP8 released checkpoint の weight_scale_inv path 対応(b11709)、UI に **quant-sidecar ダウンロード UI**(b11714)。
