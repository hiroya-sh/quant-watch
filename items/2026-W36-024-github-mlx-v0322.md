## 日本語要約
小規模なパッチ。MoE の量子化 matmul と MXFP8 block scale の丸めに関する修正が中心。

## focus 突合(release body 全文スキャン)
- focus method / model いずれも出現なし(v0.32.1 と異なり NVFP4 の明示的言及なし)

## 量子化関連の変更点
- `Skip unnecessary simdgroup computations for quantised MOE matmuls on NAX` (#4352)
- **`Round mxfp8 block scales up to avoid saturation`** (#4353)
- `Fix quantized kernels in JIT build` (#4372)、`Fix quantizing sliced arrays` (#4381)
- GGUF metadata の文字列/配列値の境界チェック (#4212)

## 影響範囲
- Apple Silicon で MXFP8 を使う場合、block scale の飽和が修正される。
