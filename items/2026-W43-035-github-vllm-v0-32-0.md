## 日本語要約
v0.32.0 本リリース(814 commits / 363 contributors)。**低精度 KV cache の全面展開**: NVFP4 KV cache が SM8x/SM12x/SM90 + XQA decode / MiniMax-M3 sparse attention(SM100)、GLM-5.x は SM100 で FP8 KV cache が既定(+2.3-5.5% スループット、TTFT -7-11%)、`fp8_ds_mla` SM90 で GLM-5.3-Flash 出力スループット +31%、ROCm に 4-bit `ultraquant_4bit` KV cache(FP8 比 2 倍の密度)。Model Runner V2 が ROCm の既定に。各種起動高速化(`vllm download-kernels` / `vllm preload`)、EmbeddingGemma 2 / MiniCPM-V 4.7 / Nemotron 3.5 ASR 対応、`/v1/systemone` 構造化推論エンドポイント追加。Python 3.10 サポート終了。

## 量子化関連の変更点
- **NVFP4 KV cache**: SM8x/SM12x #46963、SM90 #60620、XQA decode SM12x #60452、MiniMax-M3 sparse SM100 #59300
- **GLM-5.x FP8 KV デフォルト** (SM100): #60140, #60281 — KV メモリ半減、スループット +2.3-5.5% / TTFT +7-11%
- **fp8_ds_mla on SM90**: GLM-5.3-Flash で出力スループット最大 +31% #59246
- **ROCm ultraquant_4bit KV cache**: FP8 比 ~2x 密度 #57057
- MiniMax-M3 の **NVFP4 KV cache + sparse attention + draft KV view** 対応 #59300
- GLM-5.3 sparse MLA index 層間共有 (#59464, 3.5-3.9x)、fused multi-step draft decode (+13.3%, #57443)
- DeepSeek-V4/V4.1 decoder-side SWA bounded replay、encoder CUDA graph packing (TTFT -11%, #58925)
- Qwen3.8-Flash-Next (Qwen4Exp) merged QSA projections (1.45-1.68x, #59533)
- Breaking: cascade attention 削除、`mamba_cache_mode="all"` 削除、torch.compile 列並列/AsyncTP パス削除
