## 日本語要約
MLX v0.32.4(パッチリリース)。核は **1-bit affine quantization サポート** (Metal) #3161 の着地、**fp_gather_qmv / gather_qmm_rhs_sm80 の CUDA 最適化**(gather_qmm 向け)、**8-bit に満たない非 8 倍出力に対する fast qmv kernel 使用**、split-K quantized matmul partial を fp32 保持、M1 のタイル分割チューニング、SDPA / Metal 複素数 / Winograd 無効化スイッチ、他は多数のバグ修正。

## 量子化関連の変更点
- **1-bit affine quantization support (Metal)** #3161
- **[CUDA] fp_gather_qmv** for gather_qmm optimization #4508
- **[CUDA] gather_qmm_rhs_sm80** #4554
- **split-K quantized matmul partials を fp32 保持** #4641
- Use fast qmv kernel for outputs not divisible by 8 #4516
- M1 quantized matmul dispatch tuning for 6-row large shapes #4629
- Scaled dot product attention の VJP、gated delta net の VJP
- Python 3.15 / 3.15t 対応
- 多数の view / stride 系バグ修正

## 注目度コメント
本リリースは実装側の変更が主。
