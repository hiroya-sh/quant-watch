rc2(wheel は 1.4.0rc2.post1)。**Cosmos3-Edge Reasoner #20307**、**GLM-5.2 NVFP4 low-latency decode (Rubin / Modeling V2) #20517**、**MiniMax-M3 を Rubin で NVFP4 KV exemptions + paged FMHA #20167**、**Qwen3.8-Flash-Next Modeling V2 を MTP / video / quantized KV に拡張 #20276**、**SM103 Modeling V2 の既定値を GPT-OSS-120B / DeepSeek-R1-0528 NVFP4 に #20267**、**FLUX.1-dev static NVFP4 + per-tensor FP8 attention(SM103) #18396**。feature: **first-N/last-N mixed-precision KV cache(native SWA) #20452**、**FP4 MLA disaggregated serving #20544**、**MXFP8 refitting(piecewise CUDA graphs + Ray) #20075**、**Kimi K3 fabric gather / KDA replay #20576**、**FlashInfer KDA prefill 融合 #20653**。

## 量子化関連の変更点

- 新規モデル: Cosmos3-Edge Reasoner #20307、FLUX.1-dev static NVFP4 + per-tensor FP8 attention(SM103) #18396
- **GLM-5.2 NVFP4 low-latency decode on Rubin(Modeling V2) #20517**
- MiniMax-M3 を Rubin で **NVFP4 KV exemptions + paged FMHA** #20167
- Qwen3.8-Flash-Next Modeling V2 を MTP / video / quantized KV に拡張 #20276
- **SM103 Modeling V2 既定を GPT-OSS-120B / DeepSeek-R1-0528 NVFP4 に** #20267
- **first-N/last-N mixed-precision KV cache(native SWA) #20452** — KV の時間方向混合精度
- **FP4 MLA disaggregated serving #20544**
- **MXFP8 refitting(piecewise CUDA graphs + Ray collectives) #20075**
- MXFP8 fused weight-scale alignment #20443、NVFP4 AWQ pre-scales + expert input scales の MoE loading #20823/#20547
- Kimi K3 fabric gather / TCPStore rendezvous / KDA replay buffers #20576、FlashInfer KDA prefill fused convolution #20653

## 影響範囲

- **Python wheel 名が 1.4.0rc2.post1**(Boost ミラー更新のための wheel-only patch)。pip install は post1 を指定。
- 新規: **first-N/last-N mixed-precision KV cache**(native SWA、#20452)は、KV の時間方向混合精度の初出。時間方向の精度切り替えを検討する場合に直撃する機能。
- FP4 MLA の disaggregated serving(#20544)は、disaggregated 構成を使う既存コードの再評価対象。
