## 日本語要約
メジャーリリース。量子化セクションが厚い: **Humming の w[2-7]a[4,8] weight-only 推論を compressed-tensors で対応** (#46390)、emulation MoE バックエンドの int4 量子化 (#48451)、INT2 XPU weight-only quant linear (#47521)、**`nvfp4_per_token` オンライン MoE 量子化** (#48538)、CuTe-DSL FlashInfer MXFP4 量子化 (#48417)、FP4 MoE 重みの Marlin/NVFP4 repack 時ピークメモリ制限 (#47851)、MLA の `kv_cache_dtype_skip_layers` 対応 (#47309)。ほかに Inkling モデルファミリのフルサポートスタック、KV-cache グループ単位の attention バックエンド選択、DSv4 向け speculative decoding 強化、FlashInfer MNNVL all-reduce RMS quant fusion など。

## 量子化関連の変更点
- 新規対応手法/フォーマット: Humming w2-7a4/8 (compressed-tensors), INT2 XPU, nvfp4_per_token オンライン MoE
- 既存手法の改善: MXFP4 CuTe-DSL カーネル、FP4 repack のメモリ制限、quant fusion 拡充
- 対応モデル拡張: Inkling ファミリ、DSv4 系

## 影響範囲
- ユーザ視点の変化: 非2冪ビット幅 (w2-7) の weight-only モデルが vLLM で直接推論可能に。MoE のオンライン NVFP4 量子化はチェックポイント変換なしの実験を容易にする
- API/CLI 変更の有無: `kv_cache_dtype_skip_layers` (MLA) 追加

## 注目度コメント
vllm-ready + moe-quant + kv-cache-quant (focus) が同時に該当する本丸リリース。特に nvfp4_per_token オンライン MoE 量子化は「Claude だけで評価実験を完結」する運用方針に直結。火曜定例の議題候補。
