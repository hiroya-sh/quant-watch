- **[最強推し]** [[items/2026-W36-018-github-vllm-v0280|vLLM v0.28.0]] — **focus の TurboQuant / NVFP4 / kv-cache-quant / moe-quant が1リリースに同居**。AMD ROCm に **4-bit TurboQuant KV cache 用の FlyDSL decode-attention カーネル (#47896)**、NVFP4 の **KV 4-over-6 scale search (#45187)**、独立した Quantization セクションと **online quantization** の整備。加えて **dynamic INT8 W8A8 MoE が W8A16 として構築されていたバグ修正 (#50833)** ← v0.28.0 未満での INT8 MoE 測定値は要再取得。
- **[強推し]** [[items/2026-W36-001-paper-h-scale-nvfp4|H-Scale]] — NVFP4 の group=16 マイクロブロックで **per-group scale を Hessian 対角プロキシで選ぶ**後処理。ModelOpt 0.46.0 の `local_hessian` Triton fast path と同じ場所を攻めており、**すぐ比較実験できる**。
- **[強推し]** [[items/2026-W36-002-paper-semkv-quality-cliff|SemKV]] — KV 量子化は **緩やかに劣化しない**。Llama-3.1-8B で **2.322 bits まで FP16 と統計的に区別不能、2.0 bits で崩壊**。KV 予算の設計に直接使える境界値。
- **[強推し]** [[items/2026-W36-005-paper-damp-recurrent-state-quant|DAMP]] — GDN/KDA の**再帰状態**の PTQ。**INT8/FP8 ですら複雑推論で劣化、INT4/NVFP4 はほぼゼロ**。進行中の Mamba/GLA プロジェクトに直撃。
- **[強推し]** [[items/2026-W36-027-hf-model-qwen3p8-flash-next-quant-wave|Qwen3.8-Flash-Next 量子化ウェーブ]] — llm-compressor 0.13.0 の **REAP expert pruning がコミュニティ配布(`REAP-256-duo-GGUF`, 5.6万DL)に到達**。論文(MoEXBench / QAH)・ライブラリ・配布モデルが同じ方向に揃った。
- **[紹介価値あり]** [[items/2026-W36-004-paper-transforms-great-inversion|Transforms for LLM Quantization: The Great Inversion]] — 「なぜ低ビット量子化では KLT 的な**集中**でなくグループ内**平坦化**が正解になるのか」を情報理論で整理。rotation/Hadamard 系の設計原理。
- **[紹介価値あり]** [[items/2026-W36-003-paper-q-strata-moe-bit-allocation|Q-Strata]] / [[items/2026-W36-006-paper-faithfulness-not-free-kv-rag|Faithfulness Is Not Free]] — MoE の mixed-precision 割当と、RAG での **INT4 KV が faithfulness を 90%超のケースで悪化**させる監査。
