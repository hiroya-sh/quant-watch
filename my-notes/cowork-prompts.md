# Cowork セッション開始テンプレート

Cowork の新しいセッションを開く際にコピペして使う定型文集。

---

## 週次内容議論用（月曜PR着 → mergeまで）

```
HANDOFF.md と weekly/2026-W{NN}.md を読んで、今週の状況を把握してください。
気になる論文があれば一緒に深掘りしましょう。
```

## 仕様変更・設定変更用

```
HANDOFF.md を読んで、状況把握してから作業を始めましょう。
今日は○○を変更したい。
```

## 特定論文の深掘り用

```
HANDOFF.md と items/2026-W{NN}-{ID}-{slug}.md を読んで、
この論文をもう少し詳しく説明してください。
```

## タグ・focus の大きな変更用

```
HANDOFF.md と my-notes/decisions.md を読んで、これまでの設定変更経緯を把握してください。
今日は taxonomy / priorities を変更したい。変更後は decisions.md に記録してください。
```

---

## チャット分割のルール

| 作業内容 | チャットの扱い |
|---|---|
| 立ち上げ・大きな仕様変更 | 独立した1チャット |
| 週次内容議論 | 月曜PR着 → mergeまでに1チャット |
| 特定論文の深掘り | 週次から派生する別チャット（必要時） |
| タグ・focus の微修正 | 週次チャット内で済むなら分けない |
| タグ・focus の大きな変更 | 別チャット |

**基本ルール**: テーマが変わったら新チャット。
**注意**: 1チャットで「議論 + タグ追加 + 仕様変更」を全部やると compacting に追われるので分ける。
